# HTTP Explained

Xavier Hinesman · IT 3203 · Fall 2026

Project Milestone 1 adapts Assignment 1 research into seven informational pages.
Open index.html, or visit https://xhinesman05.github.io/webdevsite/ .

## Files
- index.html: introduction, key terms, and table of contents
- history.html: HTTP development and milestones
- how-http-works.html: messages, methods, statuses, and application features
- versions.html: HTTP/2, HTTP/3, QUIC, and version comparison
- concepts.html: seven definitions with examples
- references.html: cited sources and further reading
- about.html: student profile and project purpose
- site.css: the only stylesheet, shared by every page
- http-exchange.svg: original request/response illustration

The site uses semantic HTML, one custom stylesheet, Grid, and Flexbox.
There are no JavaScript dependencies, CSS frameworks, or external asset requirements.
All paths between project files are relative so the site also works under a repository path.

The site is a class project for https://ksuweb.github.io/IT3203/ .
