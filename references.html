References and further reading

Standards explain the rules. Developer guides help connect those rules with a working page.

The research uses standards for protocol details and developer documentation for accessible explanations. All sources were consulted on October 18, 2026. The older specifications explain historical behavior; the 2022 documents describe the modern organization of HTTP standards.

  • MDN: Overview of HTTP

    MDN contributors. Client and server roles, resources, and intermediaries.

  • MDN: HTTP messages

    MDN contributors. Message structure and differences between versions.

  • MDN: Request methods

    MDN contributors. Method meanings, safety, and idempotency.

  • MDN: Status codes

    MDN contributors. Categories and individual response codes.

  • MDN: Evolution of HTTP

    MDN contributors. Historical context and the role of SPDY.

Original specifications and historical documents

  • W3C: The early HTTP protocol

    Tim Berners-Lee. W3C historical description of the original protocol.

  • RFC 1945: HTTP/1.0

    Berners-Lee, Fielding, and Frystyk. May 1996. Informational description of HTTP/1.0.

  • RFC 2068: HTTP/1.1 (1997)

    Fielding et al. January 1997. The original HTTP/1.1 specification, retained here for historical context.

  • RFC 9110: HTTP Semantics

    Fielding, Nottingham, and Reschke, editors. June 2022. Common HTTP meaning and architecture.

  • RFC 9111: HTTP Caching

    Fielding, Nottingham, and Reschke, editors. June 2022. Storage, freshness, validation, and cache directives.

  • RFC 9112: HTTP/1.1

    Fielding, Nottingham, and Reschke, editors. June 2022. HTTP/1.1 syntax and connection management.

  • RFC 9113: HTTP/2

    Thomson and Benfield, editors. June 2022. HTTP/2 framing and streams.

  • RFC 9114: HTTP/3

    Bishop, editor. June 2022. HTTP/3 mapping onto QUIC.

  • RFC 9000: QUIC

    Iyengar and Thomson, editors. May 2021. QUIC transport and independent streams.
