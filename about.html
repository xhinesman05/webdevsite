A student project connecting technical research with the experience of reading a website.

Student profile

I am Xavier Hinesman, a student at Kennesaw State University taking Intro to Web Development in Fall 2026. This website develops my research into HTTP and its evolution into a resource that someone learning about the web can follow.

I am interested in how the decisions behind a website affect the experience of using it. A page can look finished while a resource path, a navigation choice, or a form's behavior still needs work.

Project purpose

I chose HTTP because it connects the visible page with the exchanges that make the page available. The website adapts my Assignment 1 research into topic pages, a concept reference, and a reading list. My goal is to explain each change in terms of the problem it addresses.

The layout also applies lessons from Assignment 2. I kept navigation available, used meaningful headings, and placed styling in one file so a shared change can reach every page.
